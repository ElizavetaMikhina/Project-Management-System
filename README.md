# Project Management System

## Описание проекта

Проект представляет собой мини-версию системы управления проектами (Project Management System), которая включает фронтенд и бэкенд. Этот проект позволяет создавать задачи, просматривать доски с задачами и управлять ими через API и пользовательский интерфейс.

## Установка и запуск проекта

Для запуска проекта в локальной среде требуется Docker и Docker Compose.

### 1. Установка зависимостей

#### Установка Docker и Docker Compose

- **macOS**:

1. Скачайте и установите Docker Desktop с [официального сайта](https://www.docker.com/products/docker-desktop).
2. Убедитесь, что Docker и Docker Compose установлены, запустив команду:
     ```bash
     docker --version
     docker-compose --version
     ```

- **Linux**:
  Установите Docker и Docker Compose, выполнив следующие команды:

  ```bash
  sudo apt-get update
  sudo apt-get install -y docker-ce docker-compose
  ```

- **Windows**:
  Скачайте и установите Docker Desktop с [официального сайта](https://www.docker.com/products/docker-desktop).

### 2. Запуск приложения

#### Запуск через Docker Compose

1. Склонируйте репозиторий проекта:

   ```bash
   git clone https://github.com/ElizavetaMikhina/Project-Management-System.git
   cd Project-Management-System
   ```

2. Построение и запуск контейнеров:

   ```bash
   docker-compose up --build
   ```

3. Остановка контейнеров:
   ```bash
   docker-compose down
   ```

После этого приложение будет доступно по адресу [http://localhost:5173](http://localhost:5173), а бэкенд API — по адресу [http://localhost:8080](http://localhost:8080).

## Выбор технологий

- **TypeScript**: Использование TypeScript улучшает поддержку типов и позволяет выявить ошибки на ранней стадии разработки. Это помогает поддерживать масштабируемость и улучшает читаемость кода.

- **Ant Design**: Используется для UI-компонентов, чтобы обеспечить единообразный и современный пользовательский интерфейс с минимальными усилиями по стилизации.

- **Yarn**: Выбран для управления зависимостями и сборки проекта из-за его скорости и улучшенной работы с зависимостями по сравнению с npm.

- **Vite**: Используется для сборки фронтенд-приложения благодаря своей высокой скорости сборки и оптимизации для современных браузеров.

## Документация API

[http://127.0.0.1:8080/swagger/index.html](http://127.0.0.1:8080/swagger/index.html).

## Контейнеризация с Docker

Проект использует Docker для упрощения развёртывания как фронтенд, так и бэкенд приложений. В Dockerfile для фронтенда используется официальный образ Node.js (версия 23 slim), а для бэкенда — Alpine-образ с Go, что позволяет минимизировать размеры контейнеров и ускорить их загрузку.

Контейнеры настроены таким образом, чтобы можно было использовать их как для разработки, так и для продакшн-среды, благодаря использованию `docker-compose.yml`, который связывает контейнеры между собой.

## Команды для управления Docker

- **Сборка и запуск проекта**:

  ```bash
  docker-compose up --build
  ```

- **Остановка проекта**:

  ```bash
  docker-compose down
  ```

- **Остановка контейнеров и удаление образов**:

  ```bash
  docker-compose down --rmi all
  ```

- **Просмотр логов**:
  ```bash
  docker-compose logs
  ```
